# Lecture transcript pipeline (ElevenLabs ASR → ChatGPT / Gemini browser)

End-to-end procedure for IslamASR lecture audio. The goal is three files per session:

| File | Role |
|---|---|
| `NNN_….txt` | **Raw ASR** — never overwrite |
| `NNN_….book.md` | **Study text** — book-style Markdown from ChatGPT or Gemini |
| `NNN_….summary.md` | **Summary** — short review + outline + takeaways |

Related files:
- `transcribe.py` — ASR CLI (`--provider elevenlabs`)
- `scripts/chatgpt_book_style.py` — drives chatgpt.com in your browser (subscription, not API)
- `scripts/gemini_book_style.py` — drives gemini.google.com (**Pro**, not Flash; subscription, not API)
- `prompts/correct-islamic-citations.md` — reference rules (now folded into the browser prompts)
- `research/asr-providers-2026.md` — provider pricing notes

---

## Overview

```text
Audio (mp3/mp4)
        │
        ▼
[1] ElevenLabs ASR  (transcribe.py)
        │
        ▼
Raw transcript  (*.txt)  — keep forever
        │
        ▼
[2] Browser LLM  (chatgpt_book_style.py  OR  gemini_book_style.py)
        │  one pass: citations · clarity · drop Q&A · Farsi under Arabic · MD polish
        ▼
Book-style study file  (*.book.md)
        │
        ▼
[3] Same browser script  (--summarize)
        │
        ▼
Summary  (*.summary.md)
```

**We no longer use Fish Audio or a multi-step Cursor edit chain.** Post-ASR work is
ChatGPT (`scripts/chatgpt_book_style.py`) or Gemini Pro (`scripts/gemini_book_style.py`)
in the browser. Commands below show ChatGPT; for Gemini swap the script name and use
`--login` against gemini.google.com (profile: `~/.gemini_playwright_profile`). Always
keep Gemini on **Pro** — the script refuses Flash/Fast.

## Folder layout

Match Bayat / Qasemian numbering. **Legacy** and **new pipeline** files can coexist in the same session folder:

```text
Audios/.../Term1/
  001/
    001_….mp3
    001_….txt              ← raw ElevenLabs ASR (never overwrite)
    001_….book.md           ← new pipeline: ChatGPT study file
    001_….summary.md        ← new pipeline: ChatGPT summary
    001_….corrected.md      ← legacy (Bayat; website subtitles when `"subtitles": "edited"`)
    001_….cleaned.txt       ← legacy
    001_….corrected.txt     ← legacy
  002/
    …
```

The website builder (`website/tools/build_content.py`) copies legacy and pipeline
Markdown into `public/data/` and sets `textPipeline` on each session JSON
(`legacy` | `book` | `both`). Subtitle source is per course: `"subtitles": "raw"`
(verbatim ASR cues) or `"edited"` (default; aligned corrected/book). See
`website/README.md` and step **D)** below.

When starting the new pipeline on folders that already have legacy artefacts, move
them aside first (session folders then hold only raw `*.txt` + fresh outputs):

```bash
python scripts/reorg_pipeline_sessions.py Audios/Bayat/marefat_nafs --start 1 --end 10 --keep-pipeline
# --keep-pipeline leaves an existing fresh 001 *.book.md / *.summary.md in place
```

Legacy files land in `Audios/.../marefat_nafs/_legacy/<NNN>/`. The website tools
still read corrected/cleaned from there for subtitle alignment.

## Step 1 — Transcribe (ElevenLabs)

```bash
source .venv/bin/activate

python transcribe.py "Audios/.../001/001_lecture.mp3" \
  --provider elevenlabs \
  --language fa
```

Tips:
- Persian lecture → `--language fa`
- Mostly Arabic → `--language ar`
- Output: `001_….txt` beside the mp3 (or `-o` path)
- Re-runs use `.asr_cache_*` per chunk — free resume after a crash

### Why ElevenLabs

| | ElevenLabs | Fish (legacy) |
|---|---|---|
| Price / hour | **$0.22** | $0.36 |
| Persian | documented, 5–10% WER | undocumented |
| ~67 min lecture | **~$0.25** | ~$0.40 |
| Long file | 1 request | many 3-min chunks |

### Deliverable

`NNN_….txt` — continuous prose + optional `--- Segments ---` block.  
**Do not edit this file.** ChatGPT and summaries always trace back to it.

## Step 2 — Book-style study file (ChatGPT or Gemini Pro browser)

This replaces the old Cursor steps (citation pass, clarity edit, Farsi under Arabic, Markdown polish).

### What the model does in one pass

1. **Correct Islamic citations** — Quran, Nahj, hadith, dua; fix surah/ayah names and mangled Arabic when identifiable (search the web when needed).
2. **Clarity edit** — keep the teacher’s ideas and order; fix heavy ASR garble.
3. **Remove audience Q&A** — drop student questions, side comments, and “بلند بگویید” exchanges; keep **only the lecturer’s speech**. Garbled or poor-mic audience ASR should be **deleted**, not reconstructed.
4. **Farsi under Arabic** — under each Arabic block, add:
   ```markdown
   > **ترجمهٔ فارسی (توسط مدل، نه استاد):** …
   ```
5. **Book-style Markdown** — `##` / `###` headings, readable paragraphs, larger Arabic where helpful:
   ```html
   <p class="ayah-ar" dir="rtl" style="font-size:1.5em; line-height:2.1; font-family: Amiri, 'Scheherazade New', 'Noto Naskh Arabic', serif;">
   «…» <span class="ayah-ref">(سوره/آیه)</span>
   </p>
   ```
6. **Footer note** — ASR source, model translations ≠ teacher, Q&A omitted, Segments omitted.

### Commands

```bash
# Preview chunk plan (no browser)
python scripts/chatgpt_book_style.py Audios/.../Term1 --dry-run
# or: python scripts/gemini_book_style.py Audios/Qasemian/InsaneKamel --dry-run

# One lecture
python scripts/chatgpt_book_style.py Audios/.../Term1 --only 001
python scripts/gemini_book_style.py Audios/Qasemian/InsaneKamel --only 001

# Whole series (sequential)
python scripts/chatgpt_book_style.py Audios/.../Term1
python scripts/gemini_book_style.py Audios/Qasemian/InsaneKamel

# Parallel tabs (use carefully — rate limits; Gemini: prefer --jobs 1–2)
python scripts/chatgpt_book_style.py Audios/Bayat/marefat_nafs --jobs 3
python scripts/gemini_book_style.py Audios/Qasemian/InsaneKamel --jobs 2
```

First run on a new machine:

```bash
python scripts/chatgpt_book_style.py --login
python scripts/chatgpt_book_style.py Audios/.../Term1 --only 001 --confirm-first-send

# Gemini Pro (not Flash):
python scripts/gemini_book_style.py --login
python scripts/gemini_book_style.py Audios/Qasemian/InsaneKamel --only 001 --confirm-first-send
```

The script opens the chat site, pastes the transcript in chunks (~6000 chars), and writes `*.book.md`. Partial progress is cached in `.book_parts_<stem>/`; rerun to resume.

### Rules (hard)

| Do | Don’t |
|---|---|
| Keep the teacher’s argument and main examples | Invent ayahs or claims not in the lecture |
| Verify sacred quotes when you can (web search) | Overwrite `*.txt` |
| Label every model Farsi translation | Pretend the teacher gave those translations in class |
| Omit student Q&A and room noise | Put a short digest into `*.book.md` (that’s `summary.md`) |
| Cover the **lecturer’s** full session (minus Q&A) | Drop whole topical sections to “make it neat” |

## Step 3 — Summarize (same browser script)

After `*.book.md` exists:

```bash
python scripts/chatgpt_book_style.py Audios/.../Term1 --summarize
python scripts/chatgpt_book_style.py Audios/.../Term1 --summarize --only 003

python scripts/gemini_book_style.py Audios/Qasemian/InsaneKamel --summarize
python scripts/gemini_book_style.py Audios/Qasemian/InsaneKamel --summarize --only 003
```

Writes `*.summary.md` with:

| Section | Purpose |
|---|---|
| **خلاصهٔ کوتاه** | 5–10 sentences; shareable |
| **فهرست مطالب** | Outline matching `book.md` headings |
| **نکات کلیدی** | 8–15 bullets — claims, practices, warnings |
| **اصطلاحات و منابع** | Optional glossary + books named |

Base the summary on **`*.book.md`**, never raw ASR. Footer: model summary from the book-style transcript.

**D) Website (portal) — raw ASR subtitles**

In `website-portal/content/manaee/term1/course.json` set `"subtitles": "raw"`.
Then:

```bash

  --site-root website-portal \
```

Subtitles and **متن کامل** use raw `*.txt`; **نسخه کتابی** / **خلاصه** use

`001_play.m4a`).

## Quality checklist

- [ ] Raw `*.txt` preserved (unchanged on disk)
- [ ] ASR covers full audio (check duration vs text density)
- [ ] `*.book.md` exists — lecturer-only, readable Persian
- [ ] Sacred quotes plausible; surah/ayah names fixed where cited
- [ ] Every Arabic block has labeled model Farsi underneath
- [ ] Student Q&A removed (only teacher speech remains)
- [ ] Footer explains ASR / model work / omitted Q&A
- [ ] `*.summary.md` exists with short summary + outline + takeaways
- [ ] ElevenLabs cost noted if relevant (~$0.22/h)

## Known pitfalls

1. **Rate limits (ChatGPT / Gemini)** — use `--jobs 1`, increase `--rate-limit-wait`, rerun (chunks are cached).
2. **Headless browser blocked** — keep the window visible; sign in with `--login`.
3. **Gemini Flash by mistake** — `gemini_book_style.py` defaults to Pro and refuses Flash/Fast; confirm the picker before the first send.
4. **Unlabeled translations** — students may think the teacher translated in class; always use the model label.
5. **Summarizing raw `.txt`** — garbled citations pollute the summary; always summarize from `*.book.md`.
6. **Switching ASR provider mid-file** — cache is per provider; a re-run with another `--provider` re-bills.
7. **Raw subtitles from `book.md` alignment** — edited text on ASR clocks drifts; use `"subtitles": "raw"` in `course.json` until you have a proper corrected/aligned pass (see `website/README.md`).
